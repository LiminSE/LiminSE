Debug Myself：关于重启博客的二三事

发表于 2025-12-08

​ 实话说，从研究生入学到现在，回顾这2年的状态，我感觉自己一直像是一台配置不低但跑满僵尸进程的服务器。挺忙活但没啥进度。这几个月来，博客的创建日期赫然在目，但点进去和知乎建政区的评论一样荒芜。

​ 这种空转的状态，大概是我这段时间焦虑的根源——没有实质性的产出，所谓的忙碌就只是一场自我感动而已。

​ 这就触及到了一个灵魂问题：产出的意义。

​ 不论是作为技术出身的 Coder，还是设计立身的 Architect，我们这类人的存在感，本质上是由“产出”定义的。在社会评价体系里，它可以是什么什么奖，可以是中标的项目，也可以是 GitHub 上的绿格子。这些实实在在的、完成了转化的产出，像是一块块拼图，才能和我们本人绑定在一起，与诸多事件一道，构成他人眼里一个完整的、立体的“人”。像是工大建院的何老院士，就是要一篇文章、一个奖、一个作品这样的组合，可以说配置是拉满了。

​ 然而，讽刺的是，自认为有极强的表现欲的我，却有着极其严重的表达便秘。

​ 我几乎没有更新朋友圈的习惯。一方面是因为薄弱的项目规划能力让我觉得生活乏善可陈，没什么值得炫耀的；另一方面，则是一种根深蒂固的防御机制。虽然在每一次汇报、群聊和激烈的讨论中，我都能感受到体内那股被压抑的表达欲在横冲直撞，但我总是害怕。我怕言多必失，怕写下的文字成为呈堂证供，怕多年前射出的子弹在多年后作为回旋镖精准地打在我的膝盖上。

​ 但这并不代表我不想展示自己。事实上，这种冲动从小学就开始了。那时我就开始折腾简陋的网页，连载自己鼠绘的小漫画；到了大学，看到隔壁 CTF 协会群友炫酷的个人博客，那颗沉寂已久的“建站之心”又死灰复燃。

​ 博客这玩意儿，真的很妙。

​ 它有一种独特的、属于互联网原住民的傲娇属性。它不像社交媒体那样把内容怼到别人脸上，而是就这样静静地杵在互联网的一个角落里。这个网址可能藏得很深，像是一个秘密基地。

​ 我有种奇怪的心理：想让人来看，又不想大张旗鼓地宣传。我只有在极少数的好友私聊时，才会像交换信物一样给出网址。我有时觉得自己像《孤独摇滚》里的“吉他英雄”，在网络背后疯狂炫技，内心深处暗戳戳地期待着哪天能被“虹夏”那样的小天使偶然发现，然后被“收养”。

​ 这种扭捏体现在我生活的方方面面。比如我的个人邮箱 limin@lmse.design，我特意搞了个看起来很像样的域名。我每次发邮件时都在想：“喂，看到这个后缀，正常人都会好奇地去浏览器里输一下看看有没有个人主页吧？”

​ 但现实是残酷的——据我观察，并没有人像我这么无聊。没人发现这个彩蛋，我也就有了偷懒的借口：“反正也没人看，更不更新无所谓吧。”

​ 于是，我就这样陷入了没人看-懒得更-内容空洞-更没人看的悲惨死循环。

​ 说回正题。出于这种既扭扭捏捏想被人关注、又因为羞耻心而疏于维护的复杂心态，我的建站史简直是一部“折腾史”。

​ 从本科开始，我兜兜转转更换了不少域名。技术栈从手撸动态页面到静态生成，从 Hexo 到 WordPress，形式从博客变成奇奇怪怪的资源站、导航站。每次都是兴致勃勃地 npm install，部署上线，然后因为懒得备案、懒得续费服务器，最后让它在 404 中无疾而终。

到现在，我终于“返璞归真”，直接把静态页面挂在了 GitHub Pages 上。不用折腾服务器，倒也实惠清净。

​ 但也就是在今天，整理着电脑里堆积如山的半成品，看着空荡荡的页面，我突然意识到：必须得写点东西了。

​ 不仅仅是为了给别人看，更是为了给自己存档。如果哪天真的有“虹夏”摸到了这里，发现这竟然是一个除了 Hello World 啥都没有的“雜鱼博客” (Zaako Blog)，那才是真正的自取其辱。

​ 所以，Debug 结束。 出于这样那样很麻烦的原因，但也出于不想当一条咸鱼的决心，我觉得我又行了。

​ System Reboot. 长征开始。
